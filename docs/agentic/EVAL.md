# 固定回归题

本文只冻结题集和验收标准。不写评测脚本、不改运行时、不改样例。实现留给后面的通用评测（计划里的 S7）。

每题先过机器初筛，再由人看完整视频终审。初筛有一项失败，这题就不能算过，也不进入终审。

## 机器初筛（必过）

只检查下面四项。不靠 opacity 判断「看不见了」（见 `AGENTS.md` 的 S0 教训）。

1. **换场残留像素。** seek 到后一场的稳定帧（场中点或该场收束之后），和上一场比像素。上一场的对象、色块、字幕不得留在画面上。对象仍在场景列表里但透明，不算通过。
2. **出界 / 字叠。** 图形和文字落在画框内。文字之间、文字和主图形之间不能叠到读不成句。
3. **字幕对比度。** 字幕和说明是浅色字、深色底。文字与紧挨着的背景对比度不低于 4.5:1。
4. **数值校验。** 有数量不变量的题，不变量必须成立（见各题）。没有数量不变量的题写明「不适用」，跳过此项，不能因为缺公式判失败。

## 人工终审

机器初筛全部通过之后，人看**完整视频**，不拿抽帧代替。终审看讲没讲到考点、中间帧是否骗过数值、节奏是否能跟。终审不通过，这题不算过。

## 题集

每题一句考点。

### 1. 祖暅原理

考点：全片共用同一个半径 R，半球和圆柱挖锥在同一高度的截面面积都是 π(R²−h²)，并由此推到球体积 ⁴⁄₃πR³。

数值校验：跨场 R 相同；同一高度上两边截面积相等，且等于 π(R²−h²)；推导终点是 ⁴⁄₃πR³。

### 2. 线性代数（矩阵变换 / 向量）

考点：矩阵作用在向量上时，画面里的箭头和基要跟着变到乘出来的位置，而不是只打出矩阵公式。

数值校验：抽样若干向量，变换后的终点与矩阵乘法一致；换场后基和箭头的尺度不另起一套。

### 3. 归并排序

考点：分治时数组按正确的顺序分裂再归并，合并结果有序，换步或换场后不留下上一状态的柱和标签。

数值校验：每一步元素集合守恒（不丢、不重）；每次合并之后的那段有序；整段结束时整体有序。

### 4. Transform 的数学原理与实现

考点：把变换的数学（线性插值或矩阵）和动画实现的中间帧对上，关键帧处的画面等于公式，而不是只在收束帧看起来对。

数值校验：在选定的参数 t 上，画面位置或矩阵与公式一致；跨场共用同一组端点或矩阵，不在下一场换成另一套数。

### 5. 心理学小知识

考点：没有公式也能把一个心理学概念讲清楚——概念、例子、结论分段，字幕可读，画面不靠堆公式蒙混。

数值校验：不适用。没有数量不变量，此项记通过，不能因此判失败。换场残留、出界 / 字叠、字幕对比度仍然必过。
